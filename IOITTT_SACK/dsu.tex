\begin{frame}
\frametitle{Disjoint Set Union}
\begin{block}{Claim}
Union by Rank takes $O(log(n))$ time per query.
\end{block}
\textit{Intuition}:
By creating tree with 
\begin{itemize}
    \item rank $2$ there should be created from tree with $2$ rank $1$ trees (requires $2$ vertices)\\
    \item rank $3$ there should be created from tree with $2$ rank $2$ trees (requires $4$ vertices)\\
    \item \dots
    \item rank $n$ there should be create from tree with $2$ rank $n-1$ trees (requires $2^{n - 1}$ vertices)
\end{itemize}

We just have $n$ vertices so that the rank of merged tree will not exceed $log(n)$. So, naive union find will run in $O(log(n))$.
\end{frame}
